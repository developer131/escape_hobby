관리자 승인 / 가입 거부(프로필 정보 삭제) 적용 안내

추가 기능
- 관리자 화면에서 가입 승인 / 이용 차단
- 가입 거부·정보 삭제 버튼: 방탈출 페이지의 profiles 프로필 행만 삭제합니다.
- Supabase Auth 로그인 인증 정보는 삭제하지 않습니다. 따라서 같은 로그인 아이디/이메일이 인증 시스템에 남을 수 있습니다.
- 관리자는 다른 관리자 프로필을 승인 변경하거나 삭제할 수 없습니다.
- 승인/삭제는 관리자 여부를 확인하는 서버측 SQL 함수(RPC)로 처리합니다.

적용 순서 (모바일 가능)
1. Supabase 대시보드 > SQL Editor에서 ADMIN_BOOTSTRAP.sql을 먼저 실행합니다. 파일 안의 이메일 조건을 본인 계정에 맞게 바꾸고, 본인 계정만 is_admin=true인지 확인하세요.
2. Supabase SQL Editor에서 admin_approval_migration.sql 전체를 실행합니다.
3. GitHub 저장소에서 index.html, app.js, style.css를 이 ZIP의 파일로 교체합니다.
4. 사이트를 새로고침하고 로그아웃 후 다시 로그인합니다.

주의
- ZIP을 다운로드해도 사이트/DB에 자동 반영되지 않습니다.
- 가입 거부 버튼은 프로필 정보만 삭제합니다. 인증 계정까지 삭제하는 기능은 포함하지 않습니다.
- SQL 실행 전 파일 내용을 확인하세요.
