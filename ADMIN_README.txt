관리자 승인 화면 적용 방법

기능
- is_admin=true인 계정에만 '관리자' 메뉴가 표시됩니다.
- 관리자 화면에서 가입 계정 목록을 확인하고 승인/이용 차단을 할 수 있습니다.
- 다른 관리자 계정은 목록에 표시하지 않으며, 화면에서 관리자 권한을 부여하는 기능은 없습니다.
- 승인 변경은 서버측 RPC에서 관리자 여부를 재확인합니다.

적용 순서
1. Supabase > Authentication > Users에서 내 계정이 실제로 존재하는지 확인합니다.
2. ADMIN_BOOTSTRAP.sql을 열어 이메일 조건을 내 계정에 맞게 수정합니다.
   - 아이디 가입 계정이면 `아이디@users.escape-log.invalid`
   - 기존 이메일 가입 계정이면 실제 이메일 주소
   실행 후 결과 확인 쿼리에서 내 계정 한 건만 is_admin=true인지 확인하세요.
3. Supabase SQL Editor에서 admin_approval_migration.sql 실행합니다.
4. GitHub Pages에 index.html, app.js, style.css를 반영합니다.
5. 로그아웃 후 다시 로그인합니다. '관리자' 메뉴가 표시되어야 합니다.

주의
- 이 ZIP은 코드 변경 파일입니다. 사이트/DB에 자동 배포되지는 않습니다.
- 관리자 권한을 부여하는 최초 1회 설정은 반드시 내 계정의 실제 로그인 이메일을 지정해야 합니다. 이 단계 없이 관리자가 자동으로 생기지는 않습니다.
