이번 수정본에 포함된 계정 기능
- 로그인/회원가입 화면 분리
- 로그인 후 내 정보 화면에서 닉네임 변경
- 로그인 후 내 정보 화면에서 비밀번호 변경
- 비밀번호는 Supabase Auth의 updateUser API로 변경
- 닉네임은 profiles.nickname만 수정하도록 권한 제한 SQL 제공

중요: 이 코드의 아이디 로그인은 username@users.escape-log.invalid 방식으로 생성된 계정에 동작합니다.
기존에 실제 이메일로 만들어진 계정은 아이디 입력만으로 자동 연결되지 않습니다. 기존 계정의 이메일을 대시보드에서 임의로 바꾸거나 auth.users를 SQL로 수정하지 마세요. 기존 계정까지 username 로그인으로 바꾸려면 안전한 서버 측 username-login Edge Function을 별도로 배포해야 합니다.

닉네임 변경 실패 시 account_profile_policy.sql을 Supabase SQL Editor에서 검토 후 실행해야 할 수 있습니다. 기존 RLS 정책을 먼저 확인하세요.
